# Security Policy

## Scope

This repository is a personal portfolio project: a detection-engineering lab built against a deliberately attackable AWS environment that I own and operate in an isolated account.

- The lab is **intentionally vulnerable**. Do not deploy it in production or in any account you don't fully control.
- Attack simulations in this repo must only be run against infrastructure you own.
- No real or sensitive data is used anywhere in this project.

## Reporting a vulnerability

If you find a security problem in this repository (for example an exposed secret, an unsafe workflow, or a flaw in the detection logic that could mislead someone), please report it privately:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.

Please don't open a public issue for security reports. This is a personal project, so there is no formal response-time guarantee, but I will look at reports as soon as I can.
